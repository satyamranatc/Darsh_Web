# Darsh — Official Documentation & Showcase Platform

An OLED Black, high-performance web platform and documentation hub for **[Darsh](https://pypi.org/project/darsh/)** (v2.0.1): The Calm, Pythonic Charting & Dashboard Engine.

## Stack
- **Frontend**: Vite 8 + React 19 + Tailwind CSS v4 + Radix UI / shadcn/ui + Lucide Icons
- **Backend**: Node.js + Express API server
- **Design System**: True OLED Black (`#000000`), glassmorphic borders, ambient glows, fluid micro-interactions

## Getting Started

### 1. Launch Frontend Docs Website
```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) to view the documentation site and interactive playground.

### 2. Launch Backend API (Optional)
```bash
cd backend
npm install
npm run dev
```
Runs on [http://localhost:5000](http://localhost:5000).

## Features
- **Interactive Playground**: Real-time code & visual simulation across 1-liners, senior dev editability, 3D charts, cards & fluid grids, data cleaning, and reactive dashboards.
- **Searchable API Explorer**: Complete interactive reference covering every Darsh function with signatures, parameter tables, and runnable examples.
- **Core Philosophy Manifesto**: Direct embodiment of the Darsh design tenets ("Extremely simple on the surface. Extremely powerful underneath.").
